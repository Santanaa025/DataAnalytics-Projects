# DataAnalytics-Projects
Portfolio projects inspired by real-world challenges from my professional experience, developed using fictional data in compliance with Brazil's General Data Protection Law (LGPD).

# IMPORTANT

This repository was created to document and organize the challenges I have encountered in my professional experience, along with the solutions I have developed for them.

In some cases, I only have access to tools such as Microsoft Excel. However, in this portfolio, I will also explore how these challenges can be addressed using other tools, such as Power BI.

The goal is to demonstrate different approaches to solving practical problems through data analysis and visualization.
